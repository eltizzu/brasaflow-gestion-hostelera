# Demo Guiada De BrasaConnect Para Cliente

## 1. Objetivo De La Demo

Mostrar BrasaConnect Como La App Hermana Que Conecta Negocios Hosteleros Con Proveedores.

La Demo Debe Dejar Claro Que BrasaConnect No Reemplaza A BrasaFlow.

BrasaFlow Ordena El Negocio Por Dentro.

BrasaConnect Ordena La Relacion Entre El Negocio Y Sus Proveedores.

## 2. Mensaje Principal

BrasaConnect Permite Que El Restaurante Y El Proveedor Trabajen Sobre Un Pedido Compartido:

- Catalogo.
- Pedido.
- Estado.
- Albaran.
- Historial.
- Incidencias.

## 3. Orden Recomendado Para Mostrar

### Paso 1: Vista Red

Mostrar La Red De Proveedores.

Explicar Que El Negocio Puede:

- Buscar Proveedores.
- Ver Categoria.
- Ver Zona De Reparto.
- Ver Condiciones.
- Solicitar Conexion.

Mensaje Clave:

`El Restaurante Puede Trabajar Con Sus Proveedores Habituales O Descubrir Nuevos.`

### Paso 2: Vista Negocio

Mostrar Proveedores Conectados Y Catalogo.

Explicar Que El Negocio Puede:

- Elegir Proveedor.
- Ver Productos.
- Revisar Formato Y Precio.
- Crear Pedido Desde Catalogo.

Mensaje Clave:

`El Pedido Nace Ordenado Desde El Catalogo, No Desde Un Audio O Un Mensaje Suelto.`

### Paso 3: Pedidos

Mostrar El Pedido Conectado.

Explicar:

- Estado Del Pedido.
- Articulos.
- Total.
- Fecha De Entrega.
- Historial.
- Albaran Asociado.
- Incidencias.

Mensaje Clave:

`Negocio Y Proveedor Miran El Mismo Pedido Y Ven El Mismo Historial.`

### Paso 4: Vista Proveedor

Cambiar A Vista Proveedor.

Mostrar Que El Proveedor Puede:

- Ver Pedidos Recibidos.
- Avanzar Estados.
- Registrar Albaran.
- Mantener Catalogo.

Mensaje Clave:

`El Proveedor Tiene Su Propio Panel Para Confirmar Y Gestionar La Entrega.`

### Paso 5: Albaranes E Incidencias

Mostrar Albaranes.

Explicar:

- El Albaran Queda Asociado Al Pedido.
- Si Hay Diferencia, El Negocio Marca Incidencia.
- El Historial Queda Guardado.

Mensaje Clave:

`El Pedido No Muere Cuando Se Envia: Se Cierra Cuando Se Recibe Y Se Revisa.`

Hoy BrasaConnect Ya Permite Mostrar:

- Vista Negocio.
- Vista Proveedor.
- Vista Red.

- Pedidos Desde Catalogo.
- Estados Del Pedido.
- Detalle Del Pedido.
- Timeline.
- Albaranes.
- Incidencias.
- Alta Rapida De Producto Desde Vista Proveedor.

Para Producto Real Faltaria:

- Archivos Reales Para Albaranes.
- Notificaciones.
- Busqueda Avanzada.
- Permisos Por Empresa.
- Integracion Con BrasaFlow.
- Lectura De Albaranes Con IA.

## 6. Demo Corta De 6 Minutos

### Minuto 1

Explicar El Problema: Pedidos Por WhatsApp, Llamadas, Audios Y Albaranes Perdidos.

### Minuto 2

Mostrar La Red Y Proveedores Disponibles.

### Minuto 3

Entrar Al Catalogo Y Crear Pedido Demo.

### Minuto 4

Abrir Pedidos Y Mostrar Detalle, Timeline Y Estado.

### Minuto 5

Cambiar A Vista Proveedor, Avanzar Estado Y Registrar Albaran.

### Minuto 6

Volver A Vista Negocio, Mostrar Incidencia E Historial.

## 7. Frase De Cierre

BrasaConnect Convierte La Relacion Entre Restaurante Y Proveedor En Un Flujo Ordenado: Catalogo, Pedido, Confirmacion, Albaran, Recepcion E Historial Compartido.
