## Antes De Subir A Web

- Confirmar Que Cada Demo Tiene Su Propia URL.
- Mostrar Que Es Una Demo/Prototipo.
- Usar Solo Datos Ficticios.
- No Pedir Datos Reales Al Visitante.
- Revisar En Movil.
- Revisar En Escritorio.
- Verificar Que Los Botones Principales Funcionan.
- Preparar Un Texto Corto De Presentacion Para Cada Demo.
- Subir La Pagina Hub Como Entrada Principal.
- Confirmar Que Los Enlaces Del Hub Apuntan A Las URLs Finales.

## Recomendacion De Publicacion

Publicar Cada App Como Demo Independiente:

- `/brasaflow`
- `/brasaconnect`
- `/brasareservas`
- `/brasacomandas`

Y Crear Una Pagina Principal Del Ecosistema Brasa Donde Se Expliquen Las Cuatro Piezas.

Pagina Ya Creada Para Usar Como Base:

- `brasa-ecosistema.html`

## Aviso Sugerido Para La Web

`Demo interactiva con datos ficticios. Las acciones que realices sirven solo para probar el flujo del producto.`

## Riesgos Que Aun Conviene Revisar

- Prueba Visual Final En Movil Real.
- Textos De Venta De Cada Pagina.
- Hosting Elegido.
- Dominio Y URLs Finales.
- Politica De Privacidad Si Hay Formularios Reales.
- Analitica Basica Para Saber Que Demo Mira La Gente.
