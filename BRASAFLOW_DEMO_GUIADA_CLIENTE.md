# Demo Guiada De BrasaFlow Para Cliente

## 1. Objetivo De La Demo

Mostrar BrasaFlow como una base funcional y clara para ordenar la operativa interna de un negocio hostelero.

La demo no debe venderse como un producto gigante terminado para cualquier caso, sino como:

- Una app funcional avanzada.
- Una base real para un primer cliente.
- Un sistema pensado para crecer sin mezclar todo desde el principio.

## 2. Mensaje Principal

BrasaFlow centraliza en un solo lugar lo que muchos restaurantes gestionan hoy entre WhatsApp, papel, Excel y conversaciones sueltas.

El valor principal es:

- Menos desorden.
- Mejor comunicacion interna.
- Turnos y vacaciones mas claros.
- Documentos y registros mejor organizados.
- Operativa diaria mas facil de revisar desde movil.

## 3. Orden Recomendado Para Mostrar

### Paso 1: Entrada Y Perfiles

Mostrar que existen tres vistas:

- Empleado
- Encargado
- Empresa

Explicar que cada perfil ve solo lo que le corresponde.

### Paso 2: Vista Empleado

Entrar como empleado y mostrar:

- Resumen del dia.
- Turnos.
- Fichaje.
- Vacaciones.
- Chats.
- Documentos.

Mensaje clave:

`El empleado no necesita llamar ni buscar mensajes: entra y ve lo suyo.`

### Paso 3: Vista Encargado

Entrar como encargado y mostrar:

- Turnos de su area.
- Solicitudes de vacaciones.
- Inventario de su zona.
- Pedidos.
- Temperaturas.
- Documentos de su area.

Mensaje clave:

`El encargado puede resolver la operativa de su zona sin depender todo el tiempo de administracion.`

### Paso 4: Vista Empresa

Entrar como empresa y mostrar:

- Panel general.
- Empleados y puestos.
- Turnos completos.
- Fichajes.
- Vacaciones.
- Documentos.
- Configuracion del negocio.

Mensaje clave:

`La empresa tiene una vision centralizada del negocio y puede revisar todo desde arriba.`

### Paso 5: Modulos Operativos

Mostrar rapido:

- Inventario como lista base.
- Pedidos como seguimiento de lo que falta y lo recibido.
- Temperaturas como registro simple.
- Recetas y alergenos como base interna.

Mensaje clave:

`BrasaFlow no intenta reemplazar todo de golpe. Ordena primero lo interno y lo operativo.`

## 4. Que Hace Hoy BrasaFlow

Hoy BrasaFlow ya permite mostrar:

- Login simulado por perfiles.
- Vista de empleado, encargado y empresa.
- Turnos semanales.
- Fichaje.
- Vacaciones y ausencias.
- Chats internos.
- Inventario base por area.
- Pedidos y recepcion.
- Control de temperaturas.
- Documentos laborales.
- Recetas.
- Base interna de alergenos.
- Empleados, roles y permisos.
- Configuracion de marca y reglas del negocio.
- Exportaciones PDF en modulos clave.

## 5. Que Conviene Decir Como Limite Actual

Para mantener la demo honesta:

- Es una demo funcional local, no un SaaS alojado todavia.
- El login es de demostracion.
- La persistencia actual usa archivo local, no base de datos final.
- Falta preparar hosting, seguridad real y base de datos para produccion.
- La parte legal debe revisarse antes de vender formalmente.

## 6. Que Queda Como Actualizacion Futura

No meter estas ideas dentro de la demo principal salvo que el cliente pregunte.

Futuro natural:

- Multi-sede.
- Firma digital.
- Albaranes.
- Coste de recetas.
- Digitalizacion asistida por IA.
- App de comandas.
- Consulta rapida de alergenos durante el servicio.
- Reservas.
- Centralizador de mensajes.

Mensaje clave:

`La idea no es hacer una app gigante. La idea es crear un ecosistema ordenado, donde cada producto tenga su funcion.`

## 7. Demo Corta De 7 Minutos

### Minuto 1

Explicar el problema: demasiada informacion repartida entre WhatsApp, papel, Excel y llamadas.

### Minuto 2

Mostrar vista empleado: resumen, turnos, fichaje y vacaciones.

### Minuto 3

Mostrar vista encargado: turnos de area, pedidos, inventario y temperaturas.

### Minuto 4

Mostrar vista empresa: empleados, puestos, documentos y configuracion.

### Minuto 5

Mostrar pedidos y recepcion como ejemplo operativo concreto.

### Minuto 6

Mostrar documentos, PDFs y registros.

### Minuto 7

Cerrar con estado actual y proximos pasos: base de datos, hosting, login real y adaptacion al negocio.

## 8. Frase De Cierre Para Cliente

BrasaFlow sirve para que el restaurante tenga su operativa interna ordenada: personal, turnos, fichajes, vacaciones, documentos, pedidos y registros en una sola herramienta, con vistas distintas para empleado, encargado y empresa.
