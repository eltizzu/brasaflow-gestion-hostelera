# BrasaConnect

## 1. Idea General

BrasaConnect Es Una App Hermana De BrasaFlow Pensada Para Conectar Negocios Hosteleros Con Proveedores.

La Idea Es Que Restaurantes, Bares, Cafeterias Y Proveedores Puedan Trabajar De Forma Mas Ordenada:

- El Negocio Ve Proveedores.
- El Proveedor Tiene Perfil Y Catalogo.
- El Negocio Hace Pedidos Desde La App.
- El Proveedor Recibe, Confirma Y Gestiona El Pedido.
- Ambas Partes Ven Historial, Estados, Albaranes E Incidencias.

BrasaConnect No Reemplaza A BrasaFlow.

BrasaFlow Ordena La Operativa Interna Del Negocio.

BrasaConnect Ordena La Relacion Entre El Negocio Y Sus Proveedores.

## 2. Frase Simple De Producto

BrasaConnect Es Una Red Para Hosteleria Donde Negocios Y Proveedores Se Conectan Para Ver Catalogos, Hacer Pedidos, Gestionar Albaranes Y Mantener Un Historial Compartido.

## 3. Problema Que Resuelve

Hoy Muchos Pedidos A Proveedores Se Hacen Por:

- WhatsApp
- Llamadas
- Audios
- Papel
- Fotos De Listas
- Mensajes Sueltos
- Albaranes Que Quedan Perdidos

Eso Genera Problemas:

- Pedidos Poco Claros.
- Falta De Historial.
- Diferencias Entre Lo Pedido Y Lo Recibido.
- Precios O Formatos Confusos.
- Albaranes Dificiles De Encontrar.
- Mucho Tiempo Perdido Entre Negocio Y Proveedor.

BrasaConnect Puede Convertir Esa Relacion En Un Flujo Ordenado.

## 4. Perfiles Principales

### Negocio Hostelero

Puede Ser:

- Restaurante.
- Bar.
- Cafeteria.
- Hotel.
- Catering.
- Grupo De Restauracion.

Puede Hacer:

- Crear Perfil De Negocio.
- Guardar Proveedores Habituales.
- Buscar Nuevos Proveedores.
- Ver Catalogos.
- Hacer Pedidos.
- Repetir Pedidos Anteriores.
- Ver Historial.
- Recibir Albaranes.
- Marcar Pedido Como Recibido.
- Marcar Faltantes, Diferencias O Incidencias.

### Proveedor

Puede Ser:

- Bebidas.
- Carnes.
- Pescado.
- Verduras.
- Panaderia.
- Limpieza.
- Packaging.
- Congelados.
- Vinos.
- Productos Gourmet.

Puede Hacer:

- Crear Perfil De Proveedor.
- Cargar Catalogo.
- Indicar Zonas De Reparto.
- Indicar Dias De Entrega.
- Definir Pedido Minimo.
- Recibir Pedidos.
- Confirmar O Rechazar Pedidos.
- Cambiar Estados.
- Subir Albaranes.
- Ver Historial Por Cliente.
- Publicar Novedades O Promociones.

## 5. Flujo Principal

1. El Proveedor Crea Su Perfil.
2. El Proveedor Carga Productos, Formatos, Precios Y Disponibilidad.
3. El Negocio Busca O Selecciona Un Proveedor.
4. El Negocio Arma Un Pedido Desde El Catalogo.
5. El Pedido Se Envia Al Proveedor.
6. El Proveedor Lo Confirma, Ajusta O Rechaza.
7. El Proveedor Marca El Pedido Como Preparado O En Reparto.
8. El Negocio Recibe La Mercancia.
9. El Negocio Confirma Si Coincide O Si Hay Incidencia.
10. El Albaran Queda Guardado.
11. El Historial Queda Disponible Para Ambos.

## 6. Estados Del Pedido

Estados Posibles:

- Borrador.
- Enviado Al Proveedor.
- Confirmado.
- Ajustado Por Proveedor.
- En Preparacion.
- En Reparto.
- Entregado.
- Recibido Conforme.
- Recibido Con Incidencia.
- Cancelado.

## 7. Albaranes

### Version Simple

- El Proveedor Sube Un PDF O Foto Del Albaran.
- El Negocio Lo Puede Ver Desde El Pedido.
- El Negocio Marca Si Coincide O No.
- Queda Guardado En El Historial.

### Version Avanzada

Mas Adelante Se Puede Agregar IA:

- Leer Productos Del Albaran.
- Leer Cantidades.
- Leer Precios.
- Comparar Contra El Pedido.
- Marcar Diferencias.
- Actualizar Costes.
- Relacionar Ingredientes Con Recetas De BrasaFlow.

## 8. Marketplace O Red

BrasaConnect Puede Crecer Como Una Red Tipo Marketplace.

Cada Negocio Y Cada Proveedor Puede Tener Perfil.

### Perfil De Negocio

- Nombre.
- Tipo De Negocio.
- Ciudad.
- Numero De Locales.
- Categorias Que Compra.
- Proveedores Conectados.

### Perfil De Proveedor

- Nombre.
- Categoria.
- Zona De Reparto.
- Catalogo.
- Condiciones.
- Pedido Minimo.
- Dias De Entrega.
- Contacto Comercial.

### Busqueda

El Negocio Podria Buscar Por:

- Categoria.
- Ciudad O Zona.
- Tipo De Producto.
- Disponibilidad.
- Proveedores Cercanos.
- Proveedores Recomendados.

## 9. MVP Recomendado

No Empezar Con Un Marketplace Completo.

Primero Conviene Hacer Algo Mas Controlado:

### Fase 1: Proveedores Habituales

Dentro De BrasaFlow O Como Primer BrasaConnect:

- Crear Proveedores.
- Crear Productos Por Proveedor.
- Hacer Pedido A Proveedor.
- Guardar Historial.
- Registrar Recepcion.
- Adjuntar Albaran.

### Fase 2: Portal Proveedor

El Proveedor Tiene Su Propia Entrada:

- Ve Pedidos Recibidos.
- Cambia Estados.
- Confirma Cantidades.
- Sube Albaran.
- Actualiza Catalogo Basico.

### Fase 3: Red / Marketplace

Despues Se Abre La Red:

- Perfiles Publicos.
- Busqueda De Proveedores.
- Solicitud De Conexion.
- Catalogos Visibles.
- Proveedores Recomendados.
- Promociones.

## 10. Conexion Con BrasaFlow

### BrasaFlow Envia A BrasaConnect

- Negocio.
- Areas.
- Inventario Base.
- Productos Que Se Piden Habitualmente.
- Pedidos Internos.
- Recepciones.
- Incidencias.

### BrasaConnect Devuelve A BrasaFlow

- Pedidos Confirmados.
- Historial Por Proveedor.
- Albaranes.
- Precios Reales.
- Diferencias Entre Pedido Y Recepcion.
- Datos Para Coste De Recetas.

## 11. Conexion Con Otros Productos

### Con Comandas

Mas Adelante, Comandas Puede Alimentar Datos De Consumo:

- Platos Mas Vendidos.
- Productos Mas Usados.
- Productos Agotados.
- Necesidad De Reposicion.

### Con Recetas

BrasaFlow Puede Cruzar:

- Ingredientes.
- Proveedores.
- Precios.
- Albaranes.
- Coste Por Plato.

## 12. Modelo Comercial Posible

### Para Negocios

Puede Entrar Como Extension De BrasaFlow:

- BrasaFlow Operativa.
- BrasaFlow Pro.
- Add-on BrasaConnect.

### Para Proveedores

Puede Tener Otro Modelo:

- Perfil Basico Gratis.
- Perfil Profesional.
- Catalogo Destacado.
- Gestion De Pedidos.
- Visibilidad En Marketplace.
- Comision Por Pedido En Una Fase Mas Avanzada.

## 13. Que No Conviene Hacer Al Principio

- No Crear Marketplace Abierto Desde El Dia Uno.
- No Meter Pagos Online Al Principio.
- No Prometer Comparador De Precios Completo.
- No Automatizar Pedidos Sin Confirmacion Humana.
- No Leer Albaranes Con IA Antes De Tener Bien El Flujo Manual.

## 14. Nombre Comercial

Nombres Posibles:

- BrasaConnect.
- BrasaFlow Proveedores.
- BrasaMarket.
- BrasaRed.

Por Ahora El Nombre Mas Claro Es:

`BrasaConnect`

Porque Habla De Conexion, No Solo De Compra.

## 15. Decision De Producto

BrasaConnect Debe Ser Una App Hermana.

No Debe Meterse Como Un Modulo Pesado Dentro De BrasaFlow.

La Relacion Ideal Es:

- BrasaFlow: Gestion Interna Del Negocio.
- Comandas: Servicio En Tiempo Real.
- BrasaConnect: Conexion Entre Negocios Y Proveedores.

Asi Cada Producto Tiene Un Rol Claro Y Puede Crecer Sin Confundir Al Usuario.
