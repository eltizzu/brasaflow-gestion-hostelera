# Documento Comercial De BrasaFlow

## 1. Que Es BrasaFlow

BrasaFlow Es Una Plataforma De Gestion Para Hosteleria Pensada Para Centralizar La Operativa Interna Del Negocio En Un Solo Lugar.

Su Objetivo Es Que:

- El Empleado Use La App Desde El Celular.
- El Encargado Controle Su Area Sin Perder Tiempo.
- La Empresa O Administracion Tenga Vision General Del Negocio.

BrasaFlow No Nace Como Una Simple App De Turnos. Nace Como Una Herramienta Para Ordenar El Dia A Dia Del Restaurante.

## 2. Que Problema Resuelve

Muchos Negocios De Hosteleria Trabajan Con La Informacion Repartida Entre:

- WhatsApp
- Papel
- Excel
- Llamadas
- Mensajes Sueltos
- Carpetas Fisicas

Eso Genera Problemas Como:

- Horarios Mal Comunicados
- Vacaciones Confusas
- Fichajes Desordenados
- Documentos Dificiles De Encontrar
- Pedidos Poco Claros
- Registros Internos Repartidos
- Falta De Control Operativo

BrasaFlow Centraliza Todo Eso Dentro De Una Misma Plataforma.

## 3. Para Quien Esta Pensado

BrasaFlow Esta Pensado Principalmente Para:

- Restaurantes
- Bares
- Cafeterias
- Locales De Hosteleria
- Negocios Con Cocina, Sala O Barra

Tambien Puede Evolucionar Hacia:

- Grupos De Restauracion
- Cadenas
- Franquicias
- Negocios Multi-Sede

## 4. Como Se Usa

La Logica De Uso Es Simple:

- El Empleado Entra Desde Su Celular.
- El Encargado Entra Desde Su Celular O Tablet.
- La Empresa O Administracion Puede Entrar Desde Ordenador O Celular.

Cada Perfil Ve Solo Lo Que Le Corresponde.

## 5. Perfiles De Usuario

### Empleado

El Empleado Puede:

- Ver Sus Turnos
- Fichar Entrada Y Salida
- Ver Sus Vacaciones
- Pedir Vacaciones O Ausencias
- Ver Chats
- Consultar Sus Documentos
- Consultar Inventario De Su Zona
- Consultar Temperaturas

### Encargado

El Encargado Puede:

- Gestionar Turnos De Su Area
- Revisar Solicitudes De Su Area
- Gestionar Inventario De Su Zona
- Preparar Pedidos De Su Area
- Registrar Recepciones
- Cargar Equipos De Temperatura
- Registrar Temperaturas
- Cargar Documentos De Su Area
- Consultar O Editar Recetas Si Corresponde
- Consultar La Base Interna De Alérgenos Si Trabaja En Cocina

### Empresa / Administracion

La Empresa Puede:

- Ver Todo El Negocio
- Revisar Todo El Personal
- Gestionar Empleados Y Puestos
- Gestionar Turnos, Vacaciones Y Fichajes
- Ver Todas Las Areas
- Cargar Documentos
- Configurar La Marca Y El Negocio

## 6. Modulos Principales

### Resumen

Permite Ver De Forma Rapida:

- Turnos Visibles
- Vacaciones Disponibles
- Avisos Urgentes
- Pedidos Abiertos
- Estado Del Fichaje

### Turnos

Permite:

- Ver Turnos Semanales
- Crear Turnos
- Editar Turnos
- Duplicar Semanas
- Cargar La Semana Completa De Una Persona
- Guardar Y Aplicar Plantillas

### Fichaje

Permite:

- Registrar Entrada
- Registrar Salida
- Ver Horas Trabajadas
- Revisar Jornadas Abiertas
- Preparar El Futuro Control Por Ubicacion

### Vacaciones Y Ausencias

Permite:

- Ver Saldo Disponible
- Solicitar Vacaciones
- Solicitar Ausencias
- Aprobar O Rechazar Solicitudes
- Bloquear Turnos Si La Ausencia Ya Esta Aprobada

### Chats

Permite:

- Chat General
- Chat Por Area
- Avisos Urgentes
- Conversacion Interna Organizada

### Inventario

BrasaFlow No Trabaja El Inventario Como Stock Fino En Tiempo Real.

Lo Usa Como:

- Lista Base De Productos Por Area
- Referencia De Lo Que Deberia Haber
- Punto De Partida Para Pedidos

### Pedidos

El Flujo Es:

1. Se Revisa El Inventario
2. Se Pulsa `Pedir` En Lo Que Hace Falta
3. Se Completa Cantidad, Nota Y Estado
4. Se Registra La Recepcion
5. Queda Historial

### Temperaturas

Permite:

- Cargar Equipos Por Area
- Registrar Temperaturas
- Dejar Observaciones
- Tener Trazabilidad Basica Del Control Interno

### Documentos

Permite:

- Cargar Nominas
- Cargar Contratos
- Cargar Anexos O Avisos
- Asignar Documentos A Empleados
- Ver Solo Los Documentos Que Corresponden A Cada Perfil
- Abrir O Exportar En PDF

### Recetas

Permite:

- Cargar Recetas Base
- Guardar Ingredientes
- Guardar Rendimiento
- Guardar Notas Internas
- Guardar Nota Corta Para Sala

### Alérgenos

Permite:

- Mantener La Base Interna De Alérgenos
- Ver Qué Recetas Ya Tienen La Ficha Completa
- Detectar Qué Fichas Todavía Falta Completar
- Dar Una Referencia Interna Clara Sin Mezclar El Rol De Comandas

## 7. Diferenciales Del Producto

BrasaFlow Tiene Diferenciales Muy Valiosos:

- Pensada Para Hosteleria, No Para Cualquier Oficina
- Separacion Real Por Areas Como Cocina Y Sala
- Uso Diario Desde Celular
- Centralizacion De Operativa Y Documentacion
- Base Para Registros Internos Relevantes
- Preparada Para Escalar A Multi-Sede
- Base Para Digitalizar Procesos Que Hoy Estan En Papel

## 8. Que Se Puede Descargar En PDF

Actualmente Se Puede Exportar O Imprimir En PDF:

- Turnos
- Fichaje
- Temperaturas
- Documentos Laborales

La Idea Es Que Esto Sirva Para:

- Consulta Interna
- Archivo
- Seguimiento
- Presentacion Rapida De Registros

## 9. Experiencia De Uso

BrasaFlow Esta Pensada Para Ser:

- Clara
- Rapida
- Sencilla
- Visualmente Limpia
- Facil De Usar Desde Celular

La Filosofia Del Producto Es:

- Menos Ruido
- Menos Pasos
- Mas Claridad
- Mas Orden

## 10. Versiones Del Producto

### BrasaFlow Local

Pensada Para Un Solo Local.

Incluye:

- Empleados Y Roles
- Turnos
- Vacaciones
- Chats
- Documentos
- Fichaje

### BrasaFlow Operativa

Pensada Para Locales Que Quieren Ordenar Mejor Su Dia A Dia.

Incluye Todo Lo Anterior, Mas:

- Inventario Base
- Pedidos
- Recepcion
- Temperaturas
- PDFs
- Mayor Personalizacion

### BrasaFlow Pro

Pensada Para Grupos O Multi-Sede.

Incluye Todo Lo Anterior, Mas:

- Varias Sedes
- Control Central
- Permisos Por Local
- Base Para Reportes Globales

## 11. Estado Actual Del Producto

BrasaFlow Ya Tiene Una Base Muy Clara De Producto:

- Roles Bien Definidos
- Modulos Coherentes
- Uso Responsive Para Movil
- Permisos Mas Cerrados
- Flujos Principales Ya Funcionales

Hoy Se Puede Mostrar Como:

- Demo Solida
- Prototipo Funcional Muy Avanzado
- Base Real Para Seguir Construyendo

## 12. Evolucion Natural

Sin Mezclarlo Todavia, BrasaFlow Puede Crecer Hacia:

- Version Multi-Sede
- Firma Digital
- Digitalizacion Asistida Por IA
- Lectura De Inventarios En Papel
- Lectura De Recetas En Papel
- Carga Asistida De Alérgenos
- Coste Por Plato

La Consulta Rápida De Alérgenos En Pleno Servicio Encaja Mejor En La Futura App De `Comandas`.

## 13. Posicionamiento Comercial

BrasaFlow Puede Presentarse Como:

`Software De Gestion Operativa Para Hosteleria`

O Tambien Como:

`La Plataforma Que Ordena El Dia A Dia Del Restaurante En Un Solo Lugar`

## 14. Cierre

BrasaFlow No Busca Ser Una App Mas.

Busca Ser Una Herramienta Clara, Util, Ordenada Y Realista Para Negocios De Hosteleria Que Necesitan:

- Mejor Organizacion
- Mejor Comunicacion
- Mejor Control
- Menos Caos
- Mas Informacion En Un Solo Sitio
